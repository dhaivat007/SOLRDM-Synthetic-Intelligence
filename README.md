# SOLRDM — Synthetic Observational Learning, Reasoning & Discovery Model

Native experimental synthetic intelligence framework (no pretrained LLM). Current research baseline: v0.7.

## Status

The native Python engine supports structured observation memory, symbolic reasoning, basic English intent learning, rule induction, and experimental scientific discovery. These are research prototypes, not general-purpose intelligence.

Android integration and APK builds are in progress; no verified APK has been released from this repository yet.

## Security

Never commit API keys, signing keys, user data, or research databases. Internet learning must use approved sources and validation gates.
