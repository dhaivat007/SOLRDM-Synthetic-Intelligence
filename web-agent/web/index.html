A partner for thinking and doing

With a model connected, chat in everyday language, ask for opinions with reasons, review files, and work through tasks. The agent can choose its research and scientific tools within a request.

  • ResearchFind papers and source links. Metadata and abstracts are not a full paper review.
  • Scientific toolsProjectile motion, damped oscillation, descriptive statistics and weighted decisions. Each result shows its assumptions.
  • FilesImages, PDFs and text. Videos are sampled into six frames; audio and events between frames are not analyzed.
  • DecisionsCompare alternatives and make recommendations. No sending messages, purchasing, deleting files or unrestricted code execution.

Your data

Conversation history stays in this browser and does not sync between devices. Sending a message sends its text, recent conversation context and selected files to the configured model provider. Attachment bytes are not retained after sending. Attach a file again when asking for a fresh review or details not captured in the previous response. Use Export to keep a copy of your conversation.

This web app is a separate assistant interface. It does not run the complete SOLRDM v0.7 Python engine or claim general intelligence.
