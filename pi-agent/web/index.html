Settings & diagnostics

Use local inference for offline conversation, or configure an online provider. Online requests send the current conversation and attached file contents to that provider.

Local runtime

The installer provides the runtime separately from model weights. A GGUF file cannot run on its own.

Optional online model provider

Images and sampled video frames need an online vision model. Local GGUF profiles accept text, including text extracted from PDFs. Video audio is not transcribed.

The key is stored by the local service, never in browser history. A configured provider may charge for use.

What this app can do

Converse using a loaded compatible model, review supported file content, run bounded tools, retrieve research sources, and keep reviewed observations. Tasks are limited to the tools exposed here. It does not operate other applications, continuously browse the internet, or train itself from unreviewed material.

Small local models may struggle with complex reasoning. Treat calculations, source citations, and simulations as evidence to inspect, not guarantees.
